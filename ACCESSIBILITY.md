# Accesibilidad

El objetivo es WCAG 2.2 AA. La base incluye HTML semántico, enlace de salto, jerarquía de encabezados, foco visible, controles táctiles, menú con Escape, bloqueo de scroll, restauración de foco, selector de idioma y respeto a `prefers-reduced-motion`.

## Verificación pendiente

- teclado completo y lector de pantalla en navegación;
- contraste final después de confirmar el dorado de marca;
- zoom 200 % y texto ampliado;
- Safari e iOS VoiceOver;
- TalkBack en Android;
- formulario con etiquetas, errores asociados y `aria-live` cuando se implemente;
- auditoría de texto alternativo con las imágenes finales.

ARIA se utiliza solo en controles que requieren estado; la estructura de contenido depende de elementos nativos.
